# test_patterns/

Per-node AXI stimulus for `axi_file_master`, consumed by `make sim CONFIG=<config> PATTERN=<p>`.

Everything under this directory is generated by `make sim-gen CONFIG=<config> PATTERN=<p> [SEED=<n>]`
(`sim/tools/gen_test_patterns.py`) and gitignored. `make clean` runs `git clean -fdx` on this
directory, so it removes generated stimulus but spares whatever git tracks.

`mesh_2x2/neighbor/` is the one tracked example, regenerated with `SEED=1` so it is reproducible.
It lets a fresh clone run `make sim CONFIG=mesh_2x2 PATTERN=neighbor` with no `sim-gen` first.
Regenerate it the same way if it ever needs to change.

## Layout

`<config>/<pattern>/node<i>/{write.txt,read.txt}` — one pair per node.

## File format

Each AW/AR entry is one field per line, in `axi_file_master` parse order (`_ax_fields` in
`sim/tools/gen_test_patterns.py`):

| Field | Meaning |
|---|---|
| `axid` | AXI ID |
| `addr` | address, hex |
| `axlen` | burst length - 1 |
| `axsize` | burst beat size, log2(bytes) |
| `burst` | burst type (1 = INCR) |
| `lock` | |
| `cache` | |
| `prot` | |
| `qos` | |
| `region` | |
| `atop` | write only |
| `user` | AWUSER / ARUSER |

`write.txt` follows each AW entry with `axlen + 1` beat lines, `"0x<data> 0x<strb> 0"`, full
strobe, address-in-data payload (each data byte is its own address, `& 0xFF`). `read.txt` carries
AR entries only, no beat lines.
